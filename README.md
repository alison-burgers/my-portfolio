# Asiimwe Atuhumuza Olusegun | Portfolio

A responsive personal portfolio website for **Asiimwe Atuhumuza Olusegun**, a Computer Science student at Uganda Christian University.

## Built with
- HTML
- CSS
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a GitHub repository named `my-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder.
3. Open the repository's **Settings**.
4. Select **Pages** from the sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish the site. The address will usually be:
   `https://YOUR-USERNAME.github.io/my-portfolio/`

Replace `YOUR-USERNAME` with your GitHub username. If you choose a different repository name, use that name in the URL.

## Updating your portfolio
Edit the HTML and CSS files, then upload the changed files to the repository. GitHub Pages republishes the site after the changes are processed.
